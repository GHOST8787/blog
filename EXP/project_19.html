Skills 學程進度檢查：
把三學程 59 門課的完成度一頁攤開的 Chrome 擴充

Engineering Chrome Extension Open Source
2026.06 BY GHOST_1010

「Google 數位人才探索計畫」要修完三個學程：AI 職場通識、數位行銷、Google Cloud，加起來 59 門課，散在 skills.google 的各條學習路徑頁裡。平台只在每一頁各自顯示完成勾，整個計畫缺一張跨學程的總表，想知道「還差哪幾門」就得一頁頁點進去數。這個 Chrome 擴充在課程頁靜默讀完成狀態，對照計畫的母清單，在工具列彈窗把三學程各缺哪幾門攤開。權限只有 storage，純讀取，不點擊頁面，也不送出任何資料。

前情提要

這個計畫的課程掛在 Google 兩個站上：大部分在 skills.google（原 Cloud Skills Boost），少數行銷認證在 Skillshop。同一門課常重複出現在不同學程的路徑底下，例如「生成式 AI：瞭解基礎概念」三個學程都要修。手動追蹤時，光是判斷「這門我修過了沒、它算在哪個學程」就很容易數錯。把完成狀態交給瀏覽器讀，省掉人工對帳。

# 它要解決的問題

skills.google 是單頁式應用，每門課的完成狀態只在你逛到那一頁時才渲染出來，而且分散在好幾條路徑頁底下。平台給的是「單門課的勾」，沒有「整個計畫還剩多少」這層視角。要自己算進度，得把三學程的清單抄下來、一頁頁點開、逐門核對，過程繁瑣又容易漏。這個擴充把這件事自動化：你照常瀏覽，它在背景記住每門課的完成與否，彈窗一開就是一張分學程的總表。

# 怎麼運作

整個擴充分三塊：頁面端讀狀態、本機存進度、彈窗算總表。

一、content script 靜默讀完成狀態

注入到 skills.google 與 cloudskillsboost.google 頁面的 content script，掃描頁面上的 ql-activity-card 卡片，讀它的 completed 屬性判斷該門課完成沒，再用網址裡的 course_templates/{id} 數字 id 當鍵。配對只認這個 id、忽略 /paths/{X}/ 前綴，所以同一門課不管掛在哪個學程的路徑底下都對得起來。整段純讀 DOM，不在頁面畫任何東西，也不替你點任何按鈕。

二、累積存進 chrome.storage.local

每次讀到的狀態併進 chrome.storage.local，完成標記採 sticky-true：一旦某門課被記成完成，之後就算逛到沒渲染出狀態的頁面也不會被蓋回未完成。寫入前先比對舊值，只有真的變動才落盤，所以背景常駐的成本很低。

三、彈窗用母清單算三學程進度

工具列彈窗拿計畫的母清單和存下來的進度做交集，每門課歸到三態之一：完成（✓）、未完成但已逛過該頁（✗）、還沒抓到（—，提示你去逛對應路徑頁）。Skillshop 的課在 skills.google 偵測不到，單獨標成需手動確認。彈窗按學程分組，每組標出「已完成 / 可偵測門數」，再附一個「一鍵掃描全部」按鈕，會在背景把所有相關路徑頁開起來、等 content script 掃完再關掉，最後刷新總表。

# 母清單與三學程

母清單是計畫官方要求的課程，三學程合計 59 門課（含跨學程重複的）。去掉重複後可自動偵測 45 門，另有 5 門 Skillshop 認證在 skills.google 之外、需手動確認，計畫最後還有一門總整課程走官方 LINE 也偵測不到。

學程 課程數 偵測方式
AI 職場通識學程 33 全部自動偵測
數位行銷學程 15 10 門自動偵測，前 5 門 Skillshop 手動確認
Google Cloud 學程 11 全部自動偵測
去重後總計 可偵測 45 ＋ Skillshop 5 門手動 ＋ 總整課程走 LINE

# 工程上的幾個決定

  • 用 2 秒輪詢取代 MutationObserver — 頁面的卡片是非同步載入的，而 skills.google 有常駐動畫，配 debounce 的 MutationObserver 會被持續的 DOM 變動餓死、永遠不觸發。改成固定每 2 秒掃一次，搭配「沒變動就不寫入」，成本可忽略又穩定。
  • 完成標記 sticky-true — 同一門課在不同頁面渲染出的狀態不一定一致，逛到沒掛狀態的頁面時，已完成的勾必須守住，不能被空狀態洗掉。
  • Skillshop 單獨歸類 — 行銷學程前 5 門認證在另一個站，技術上抓不到，總表直接標「需手動確認」，免得讓人誤以為漏修。
  • 隱藏已完成 — 勾一個核取方塊就只留還沒做的課，計數先算完才隱藏，所以「已完成 / 總門數」的數字不受影響，偏好也記在 storage 裡。

# 隱私邊界

manifest 只要一個權限：storage，用來把進度存在本機。content script 的注入範圍鎖在 skills.google 與 cloudskillsboost.google 兩個網域，其他頁面碰不到。整個擴充全程只讀頁面、把完成狀態寫進你自己的瀏覽器，沒有任何對外連線，不蒐集、不上傳。

# 技術環境與限制

  • 平台 — Chrome Manifest V3，content script ＋ action popup，無背景 service worker。
  • 資料 — 進度只存 chrome.storage.local，換裝置不同步、清除瀏覽資料會一併清掉。
  • 偵測範圍 — 只認得 skills.google 上以 course_templates/{id} 標示的課；Skillshop 認證與走 LINE 的總整課程要自己確認。
  • 母清單時效 — 清單於 2026-06-05 從計畫頁與 skills.google 收集，計畫若改課程內容需同步更新 master-list.js。
