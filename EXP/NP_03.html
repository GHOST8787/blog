海科館生物資料庫建置：
從 Excel 樞紐分析到物種管理系統

Engineering Database Excel Marine Biology
2024.04 — 2024.08 BY GHOST_1010

國立海洋科技博物館（海科館）內部生物資料庫整理工作。建立統一缸體編碼 schema、整合 A/B/C 三區共 190 個缸位的清冊、整理樞紐分析做月度死亡統計。產出可查詢、可擴展的物種管理表單供館內後續維運使用。

# 缸體編碼 schema

為了讓散落在不同名稱、不同尺寸的缸位能被統一索引，重新設計編碼規則。範例：C0AF0120L01 拆解：

段 範例值 意義
類型字元 C0 / A1 / A2 / A3 / A4 主缸類型（如 A1 大池、A2 主題缸、A3 水母、A4 中型主題、C0 後場標準缸）
區域 A / B / C 後場分區（A 區、B 區、C 區）
尺寸代碼 F / J / T 等 缸型分類（標準矩形 / 圓筒 / 噸級主缸）
水體量 0120 / 0320 / 1460 公升（L）；噸級主缸用 T 後綴（如 0150T = 150 噸）
序號 L01 / L02 ... 同尺寸同區域內的流水序號

# 缸體量級

108
大型缸位（A/B/C 三區）
82
中型缸位（中間區）
190
總有效缸位

從 81 公升到 150 噸跨度，依水體量分層：

  • 噸級主缸 — 大洋池 150 噸、俯視池 35 噸、一二三槽各 50 噸
  • 主題缸 — 花園鰻 / 珊瑚 / 小丑 / 蝴蝶魚（各 3.5 噸）
  • 水母缸 — 倒立 / 馬賽克 / 海月（各 0.8 噸，共 6 缸）
  • 後場 A/B/C 區 — A 型（1,460 L）/ B 型（320 L）/ C 型（120 L）/ 檢疫缸（320 L）
  • 中型缸 — 81 L 到 723 L 不等，分布於各區後場

# 樞紐分析：月度死亡統計

以缸體編碼為樞紐主鍵，整理 4-6 月每月物種死亡與健康狀態記錄，產出按缸位、按物種、按時間切片的死亡數統計表。協助館方了解：

  • 各缸位是否有異常死亡集中
  • 哪些物種需要調整管理方式
  • 月度趨勢比較

# 整合的資料源

資料源 用途
生物盤點表 各區生物總清單，缸位 × 物種對照
缸子清冊 缸體編碼 schema 主表（新編碼 vs 舊名對照）
養殖系統日報表 每日各缸狀態（水質、餵食、處置）
未拍物種總和表 已盤點但尚無影像紀錄的物種清單
月度統計樞紐 按月切片的死亡 / 移缸 / 處置統計

# 工作流

  • 編碼設計 — 設計 schema 規則，產生「新編碼 vs 舊名」對照表
  • 資料清洗 — 把不同來源的 Excel 表統一欄位、消除重複、補齊缺失
  • 樞紐分析 — Excel pivot table 產出多角度切片（按缸 / 物種 / 月）
  • 交付 — 把樞紐 output 與原始清冊一起歸檔，供館方後續維運
