The Tarot Prompt Alchemist:
Dynamic Prompt Engineering for Generative AI

Engineering Vanilla JS Prompt Engineering
2026.02.19 BY GHOST_1010

This project is a lightweight, interactive frontend module. It simulates a random-draw mechanism, then automatically composes the relevant variables (card attributes, upright/reversed state, the user's intent domain) into a high-quality System Prompt.
The point: lower the technical barrier for end users to interact with a large language model in depth. Turn abstract psychological projection into a precise machine instruction.

Heya

An interactive web page: the user picks a topic (career / relationships / health), clicks to draw a tarot card, and the page generates a prompt for an AI tool like ChatGPT (containing the drawn card, upright / reversed orientation, topic domain, etc.). Copy-paste the prompt into the AI chat and get back a structured reading. The product is essentially a "tarot-flavored prompt generator," removing the friction of "I want to ask the tarot but don't know how to phrase it for the AI."

# Technical Implementation

Adaptive Grid & Negative-Margin Math

Rendering 78 DOM nodes (cards) on screens of every size produces overflow problems. I dropped absolute coordinates — too high-maintenance — and switched to native JavaScript that detects container width on the fly and injects a calculated negative margin. The whole dataset stays inside the viewport, no matter the device.

Rendering Optimization & Hardware Acceleration

Shuffle, fan-out, and hover-extract animations all run on CSS transform: translate3d with will-change. Render work moves to the GPU layer. The main thread stays free, framerate stays stable through the complex interactions.

Structured Prompt Construction

Core behavior: synthesize the prompt dynamically. When a draw fires, the system extracts the domain parameter, the card array index, and the orientation boolean, then assembles them into a pre-defined Prompt Template. The result has strict system-boundary constraints — no idle chat, just precise attribute mapping and logical convergence.

# Domain Knowledge: Decomposing the Tarot System

From a systems analysis angle, tarot is a framework for subconscious projection and association. Pulling visual symbols with high symbolic density forces the brain's associative network into retrieval. The hidden internal state surfaces as something readable.

Base Dataset (78 Nodes)

Major Arcana (Macro-Variables, 22)

These represent irreversible macro trends, core principles, and base environment parameters. The Fool (high entropy, initial state). The World (closed loop, system complete).
Drawing one means the analysis target carries heavy system weight.

Minor Arcana (Micro-Variables, 56)

These represent local state, execution detail, short-term feedback. The set splits into four suits:
🔥 Wands (momentum and execution)
💧 Cups (relational topology and emotion)
💨 Swords (logic and conflict)
🌍 Pentacles (material resources and structure)

Dataset Filtering Strategy

  • Macro-node analysis (recommend: Major Arcana only)
    For high-dimension questions like long-term career direction or life-stage transitions, restricting the draw to the Major Arcana filters out short-term noise. You get a core strategic read.
  • Routine event parsing (recommend: full 78 cards)
    For daily operations, short-term projects, or specific event reads, open the full set so macro trends and micro detail can intersect.
  • Targeted convergence (recommend: a single suit)
    With a sharply defined target — resource allocation (Pentacles), logical debugging (Swords) — pin the draw to one subset. Focus goes up.

Extraction Models

The draw configuration depends on the question's complexity. A few standard model shapes:

1. One-Card Pull — this project's target

The most efficient initial convergence. Useful for clarifying a single state, getting an immediate decision weight, or setting a daily baseline.

System config: this interface uses single-node extraction by default. State your input variable (the question), then click in the module below. The system will synthesize the AI instruction for deep analysis.

2. Three-Card Spread

Three adjacent nodes. Used for building a time series (past state, current variable, projected direction) or a logical chain (core problem, recommended action, expected outcome). Good for watching how nodes influence one another.

3. Celtic Cross

A matrix of 10 weighted nodes. Covers internal subconscious, external disturbance, historical resistance, long-term direction. Built for systems with many interacting variables.
