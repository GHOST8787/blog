Picking up from Part 1, this part installs the Gog skill and wires the AI assistant to a Google account — so it can run Gmail and Calendar directly.

# Step 1: Install the Gog Skill

The Gog skill needs its own CLI tool. On the VM terminal, run these to install and configure it:

# 1. Install Gog CLI
cd /tmp
curl -fsSL https://api.github.com/repos/steipete/gogcli/releases/latest \
  | grep browser_download_url \
  | grep linux_amd64 \
  | cut -d '"' -f 4 \
  | xargs curl -fsSL -o gogcli.tgz

tar -xzf gogcli.tgz
sudo install -m 0755 gog /usr/local/bin/gog

# 2. Install the Clawdbot skill
clawdbot skills install steipete/gog

# Step 2: Google OAuth

To connect Gmail and Calendar safely, set up OAuth credentials via Google Cloud:

  • In Google Cloud Console, create a project and enable the APIs you need (Gmail, Calendar, Drive, etc.).
  • Create an OAuth client ID of type "Desktop app" and download the JSON.

Upload the credential file to the VM via SCP:

scp -i <YOUR_KEY.pem> client_secret.json <YOUR_VM_USER>@<YOUR_VM_IP>:~/

Finish the auth setup on the VM:

gog auth credentials ~/client_secret.json
gog auth add <YOUR_EMAIL> --services gmail,calendar,drive,contacts,sheets,docs

This prints an authorization URL. Copy it into your local browser, sign in to Google, and complete the consent flow.

# Step 3: Verify and Use

Back in the Control UI chat, you can test it directly in natural language, for example:

> "Check my latest emails"
> "Show me my calendar for today"

Prefer to drive it from the VM terminal? You can:

# Search the 5 most recent emails
gog gmail search 'newer_than:1d' --max 5

# Show today's calendar
gog calendar events primary --from $(date -I) --to $(date -I)

# Step 4: Daily Maintenance and Caveats

To keep the system stable, a few rules to keep in mind:

  • Keep the SSH tunnel open: whenever you want to reach the Control UI, the local SSH tunnel window has to stay open. Close the tunnel and the connection drops.
  • Security reminder: never type your Google password anywhere except the official Google login page. Your token is the service key — protect it.
  • Debugging starter: if the bot stops responding, check service status and logs first:
# Service status
systemctl --user status clawdbot-gateway.service

# Live logs for debugging
journalctl --user -u clawdbot-gateway.service -n 50

Deployment done. Your cloud VM now hosts an AI assistant fully wired into the Google ecosystem.
