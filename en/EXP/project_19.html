Skills Track Progress Checker:
A Chrome extension that lays out completion of 59 courses across three tracks on one page

Engineering Chrome Extension Open Source
2026.06 BY GHOST_1010

The "Google Digital Talent Exploration Program" requires finishing three tracks: AI workplace literacy, digital marketing, and Google Cloud, 59 courses in total, scattered across the various learning-path pages on skills.google. The platform shows a completion check on each page on its own, and the whole program has no single cross-track summary table. To find out "which courses are still missing," I had to click into each page and count. This Chrome extension reads completion status silently on the course pages, cross-references the program's master list, and lays out which courses each of the three tracks still lacks in the toolbar popup. The only permission is storage, read-only, no clicking on the page, and no data sent out.

Background

This program's courses sit on two Google sites: most are on skills.google (formerly Cloud Skills Boost), and a few marketing certifications are on Skillshop. The same course often appears repeatedly under different track paths, for example "Generative AI: Understanding the Basics" is required in all three tracks. When tracking manually, deciding "have I taken this one, and which track does it count toward" is easy to miscount. Handing completion status off to the browser saves the manual reconciliation.

# The Problem It Solves

skills.google is a single-page application. Each course's completion status renders only when you browse to that page, and it is spread across several path pages. The platform gives you "a check per course," with no "how much is left across the whole program" view. To compute progress yourself, you have to copy down the three tracks' lists, click each page open, and check course by course, a tedious process that misses things easily. This extension automates it: you browse as usual, it remembers each course's completion in the background, and the moment you open the popup you get a per-track summary table.

# How It Works

The whole extension splits into three pieces: the page side reads status, the local side stores progress, and the popup computes the summary.

1. Content script reads completion status silently

The content script injected into skills.google and cloudskillsboost.google pages scans the ql-activity-card cards on the page, reads their completed attribute to decide whether the course is done, then uses the numeric course_templates/{id} id from the URL as the key. Matching recognizes this id only and ignores the /paths/{X}/ prefix, so the same course lines up no matter which track's path it sits under. The whole thing reads the DOM purely, draws nothing on the page, and clicks no buttons for you.

2. Accumulated into chrome.storage.local

Each status read merges into chrome.storage.local, with the completion flag set sticky-true: once a course is recorded as complete, browsing later to a page that does not render its status will not flip it back to incomplete. Before writing, it compares against the old value and only commits to disk on a real change, so the cost of staying resident in the background is very low.

3. Popup computes three-track progress from the master list

The toolbar popup intersects the program's master list with the stored progress and assigns each course to one of three states: complete (✓), incomplete but the page has been browsed (✗), or not yet captured (—, prompting you to browse the matching path page). Skillshop courses are undetectable on skills.google and get flagged separately as needing manual confirmation. The popup groups by track, marks "completed / detectable count" for each group, and adds a "scan everything in one click" button that opens all the relevant path pages in the background, waits for the content script to finish scanning, then closes them and refreshes the summary.

# The Master List and Three Tracks

The master list is the program's officially required courses, 59 in total across the three tracks (including cross-track duplicates). After removing duplicates, 45 can be detected automatically, another 5 Skillshop certifications sit outside skills.google and need manual confirmation, and the program has one final capstone course that runs through the official LINE and is also undetectable.

# A Few Engineering Decisions

  • 2-second polling over a MutationObserver — the page's cards load asynchronously, and skills.google has resident animation, so a debounced MutationObserver gets starved by the continuous DOM churn and never fires. Switching to a fixed scan every 2 seconds, paired with "no write on no change," makes the cost negligible and the behavior stable.
  • Sticky-true completion flag — the status a course renders on different pages is not always consistent, and when browsing to a page with no attached status, a completed check has to hold and cannot get washed out by an empty state.
  • Skillshop classified separately — the marketing track's first 5 certifications live on another site and are technically out of reach, so the summary flags them "needs manual confirmation" to avoid the impression that a course was skipped.
  • Hide completed — checking one checkbox leaves only the courses still to do. The count is computed first and then hidden, so the "completed / total" figure stays unaffected, and the preference is also stored in storage.

# Privacy Boundary

The manifest needs one permission: storage, used to store progress locally. The content script's injection scope is locked to the two domains skills.google and cloudskillsboost.google, and other pages are out of reach. The whole extension only reads pages and writes completion status into your own browser, with no outbound connections, no collection, and no upload.

# Technical Environment and Limits

  • Platform — Chrome Manifest V3, content script ＋ action popup, no background service worker.
  • Data — progress is stored only in chrome.storage.local, does not sync across devices, and gets cleared along with clearing browsing data.
  • Detection scope — it only recognizes courses marked with course_templates/{id} on skills.google; Skillshop certifications and the LINE-based capstone have to be confirmed by yourself.
  • Master list currency — the list was collected on 2026-06-05 from the program page and skills.google; if the program changes course content, master-list.js needs to be updated in sync.
